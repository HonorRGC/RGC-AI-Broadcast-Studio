### Built for league racing broadcasts

RGC AI Broadcast Studio is being built for iRacing leagues that want their race nights to feel like a real broadcast. The goal is simple: give league admins, broadcasters, and content creators a tool that can call the race, control cameras, show professional overlays, bring in sponsor graphics, and use league stats to tell better stories.

Use it as a full AI broadcast with OpenAI and ElevenLabs, or turn the AI voice off and use it as a broadcast helper with live producer notes, camera tools, overlays, and race information.

### Features

- AI Commentary
- Camera Direction
- Broadcast Overlays
- League Stats
- Producer Page
- Sponsor Support

### Two ways to use it

**Full AI Broadcast:** Connect OpenAI and ElevenLabs, start the broadcast before practice or qualifying, and let the system help create a full race-night show.

**Broadcast Helper Mode:** Turn off AI voice and use RGC AI Broadcast Studio as a producer assistant while a human broadcaster calls the race.

### Requirements

Required:

- Windows PC
- iRacing installed
- Python 3.11 during early builds
- RGC AI Broadcast Studio installer

For AI voice broadcasts:

- OpenAI API key
- ElevenLabs API key
- ElevenLabs voice IDs

Optional:

- SIMRacingApps for advanced car graphics
- Sim Racer Hub league/season IDs
- Tailscale for remote producer help
- Discord webhook for race reports
